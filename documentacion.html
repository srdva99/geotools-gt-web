Instrucciones generales para instalar y utilizar los plugins de GeoTools GT.

Instalar un plugin desde ZIP

  1. Descarga el archivo ZIP publicado para el plugin.
  2. Abre tu versión compatible de QGIS y entra a Complementos → Administrar e instalar complementos.
  3. Abre la sección Instalar desde ZIP.
  4. Selecciona el ZIP original del plugin y confirma la instalación.
  5. Activa el plugin si fuera necesario y verifica su menú o barra de herramientas.
Ya existen descargas separadas: v0.3.3 para QGIS 3.x (mínimo declarado 3.16) y v0.3.4 para QGIS 4.x. Selecciona la adecuada; valida la instalación en tu versión concreta de QGIS.

Compatibilidad y seguridad

Prueba cada versión en las instalaciones de QGIS que declares compatibles. Descarga complementos solo desde fuentes de confianza y revisa las dependencias antes de instalarlos.
